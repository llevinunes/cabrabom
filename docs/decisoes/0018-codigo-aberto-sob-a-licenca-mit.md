# ADR 0018: Código aberto sob a licença MIT

- **Status:** Aceita
- **Data:** 2026-11-01
- **Proposta por:** Usuário (código aberto) e IA (escolha da MIT)

## Contexto

É um projeto de aprendizado construído com assistência de IA.

## Decisão

Código, documentação e SVGs do ícone sob a **licença MIT**. O README pede que forks publicados usem outro nome e outro ícone, e informa como a IA foi usada.

## Alternativas consideradas

- **Código proprietário:** faria sentido para um negócio, não para aprendizado.
- **AGPL-3.0:** obrigaria versões publicadas como serviço a abrir o código; cria barreira para quem quer reaproveitar.

## Consequências

- Positivas: máxima liberdade para estudar e reutilizar.
- Negativas: a MIT não protege o nome; se o app virar negócio, o caminho é registrar a marca no INPI.
