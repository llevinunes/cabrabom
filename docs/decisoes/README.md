# Registros de decisão (ADR) do CabraBom

Para registrar uma decisão nova, copie `0000-modelo.md`, use o próximo número e adicione uma linha nesta tabela. Decisões não são apagadas: quando mudam, o ADR antigo recebe o status **Substituída por ADR NNNN**.
